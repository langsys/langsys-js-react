## Scope

A **binding**: it inherits the browser core's profile and adds nothing of its own, so most rules are the core's to satisfy. Rows take one of these shapes:

- **`implemented` · `n/a (pure)`** — behaviour this binding owns, proven in-process (jsdom), by shared vectors, or by artifact inspection with a positive control. **`implemented` · `contract`** is a row read back through the API on the SDK test clone (CONF-2), each beside a control that shows the API would have accepted what was withheld.
- **`provisional` · `mock`** — behaviour implemented, but the evidence is a stand-in or a payload asserted at the transport seam: a payload asserted at the `fetch` seam, or a stand-in API, where the real API's answer decides the property. It moves to `implemented` when the clone run reads the property back.
- **`delegated` · `-`** — the core owns it. Evidence names the core's row and an absence probe proving this binding does not participate, with the probe's firing control.
- **`partial` / `not implemented` · `-`** — the rule binds this package and the behaviour is absent or incomplete, here or in the core it delegates to. Each such row says which and what closes it.

## Probes

Every `delegated` row's evidence comes from `_dev_/family-probes.py`, which strips comments, asserts it read at least six shipped source files (tests, `src/test-helpers/` and the build-time transform excluded), and pairs each absence probe with a control that must fire in the same files. It exits 1 if any control reads zero, since a probe whose control is zero has read nothing. Current run: 22 families (the 20 of the core's rows, plus `MOVE`: the binding writes no `previous_category` and stamps no previous-identity marker; and `REF`: it authors no reference-list path or call), 0 probe hits, every control non-zero. `--selftest` plants a hit and a control in a synthetic source for every family and checks that each probe fires, that a hit in a comment is not read, and that a source holding neither reads control zero; breaking one pattern turns it red.

`_dev_/enumerate-surface.mjs` classifies public members from the core's `.d.ts`, scoped to `LangsysAppClass`, and proves five detection properties with `--selftest` before any zero it prints is read. `_dev_/check-conformance.py` validates this file against the spec files it is given: the spec's blob and specVersion in the header, one row per rule id (ICU-7 only through `--carry`), canonical statuses and tiers, delegated evidence naming a core row, probe and control, the tally table against the rows, and, with `--core`, every `Core row X: `status` (`tier`)` citation against the core's file. `--selftest` plants each of these faults and checks the validator catches it; a fault whose target text is not in the file is reported as not planted and fails the selftest.
